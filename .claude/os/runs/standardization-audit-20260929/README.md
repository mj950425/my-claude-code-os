## 바뀐 부분

- 모든 정책이 목적·허용값·자연어 규칙으로 구성되고 공통 변환기로 SDK에 전달된다. 외부 운영 프롬프트 동기화는 별도 선택 기능이다.
- 중복된 정책 절과 규칙 ID를 거부한다. 화면에서 정책 전체와 SDK에 전달하는 정확한 정책을 확인할 수 있다.
- 작업의 지원 기능과 현재 작업에 맞게 탐색 링크를 연결했다. 정책만 있는 작업에서 없는 검수 페이지를 열지 않는다.
- 보고서의 값 이름은 정책에서 가져온다. 공통 엔진에 특정 성별 이름을 고정하지 않는다.
- 의류 GT 이미지의 가져오기 경로와 누락 기록을 추가했다. 같은 상품 번호라도 플랫폼이 다르면 합치지 않는다.
- 오래된 문서·검사 기대값을 새 계약에 맞췄다. 구형 판정표 호환성은 별도 fixture로 검사한다.

## 남은 데이터 상태

- 의류 기존 골든셋 이미지는 로컬 원본 색인이 없어 준비 전이다. 복구 명령과 필요한 입력 형식은 해당 package 문서에 있다.
- 운영 증분 100개는 별도 모집단으로 이미 검수 완료했다. 최종 운영값 일치 91개, 불일치 9개다. 운영값은 사람의 확정 정답이 아니며 DB·GT에 결과를 쓰지 않았다.
- 100개 가운데 7개 상품의 원본 이미지 11장은 확보하지 못했다. 제공된 이미지 1,678장은 모두 열람한 기록을 확인했다.
