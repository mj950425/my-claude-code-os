# 공통 구현 수정 및 검증

## 발견·수정

- 정책 H2 절이 중복되면 앞 내용이 dict에서 사라질 수 있었다. 이제 중복 절을 거부한다.
- 다중 속성 정책에서 공통 규칙과 속성 규칙의 ID가 겹칠 수 있었다. 문서 전체에서 규칙 ID를 고유하게 검사한다.
- 공통 규칙 절에 숫자 우선순위나 빈 내용이 들어가면 잘못된 구조로 접수될 수 있었다. 공통 우선순위와 비어 있지 않은 규칙을 검사한다.
- 예전 테스트가 제거된 화면 배너·판정표·관찰 전용 프롬프트를 요구했다. 현재 v2 전체 정책 전달 계약을 검사하고, 예전 판정표는 별도의 고정 fixture로 호환성을 유지한다.
- 외부 Java 리소스의 동기화 상태를 SDK 정책 전달의 성공 조건으로 간주하던 테스트를 분리했다. 임시 파일로 동기화 왕복을 검사하고, 실제 외부 파일은 preview에서 변경하지 않는지 검사한다.

## 검증

- 1차 전체 검사: 472개, 실패 14개, 오류 1개. 원본 로그는 tests-round1.log에 보존했다.
- 정책 문서 검사 8개 통과: 중복 절·전역 규칙 ID·공통 규칙·5개 실제 profile 바인딩.
- 프롬프트 검사 14개 통과: 원문 및 정확한 SDK 정책 화면 노출, 동적 정책 전달, 임시 외부 리소스 동기화, 구형 판정표 호환.
- 멀티 에이전트 계약 검사 6개 통과: 다섯 작업의 모든 필드가 공통 정책을 받음, 역할/모델 전달, 스키마/참조 검사, 불일치 재검수와 한 번의 재시도.
- 이 라운드의 SDK 호출은 mock이다. 이전 운영 100개 실제 SDK 실험 기록은 수정하거나 재실행하지 않았다.

## 의류 GT 입력 복구 경로

- `import_clothing_images.py --source-index <로컬 JSONL>` 어댑터와 profile의 prerequisite를 연결했다.
- `productKey`로 이미지와 GT를 연결해 서로 다른 플랫폼의 같은 상품 번호가 합쳐지지 않는다.
- 파일 내용을 해시로 보관하고 GT 원본을 변경하지 않는다. 없는 파일과 이미지가 없는 GT 키는 manifest에 남긴다.
- 현 checkout에는 기존 GT 상품에 대응하는 이미지 원본이 없어 실제 GT 준비 상태는 유지했다. 이미 완료된 증분 100개 실험으로 대체하지 않았다.
- 로컬 임시 자료로 어댑터 검사 5개 통과. missing_input 안내에 prerequisite.note를 포함해 필요한 입력도 안내한다.

## 최종 재검증

- Luna 재검토에서 추가로 찾은 빈·중복 GT 키 덮어쓰기를 거절하도록 수정했다. 어댑터 최종 6개 검사 통과.
- 코드와 템플릿을 고정한 전체 엔진 검사 484개 통과. 어댑터까지 합계 490개 통과.
- 다섯 작업의 문서·실행·화면 독립 평가가 모두 90 이상이며 최저는 91점이다.
