# 작업별 표준화 완료 기준

사용자 목표: 모든 task의 구조와 화면 구조를 Luna 멀티 에이전트로 확인하고, 모두 90점 이상이 될 때까지 개선한다.

## 대상과 평가 방법

- attributes/*/profile.json 전체를 대상으로 한다. 현재 등록 작업 수는 실제 목록으로 확인한다.
- 문서·설정, 실행·계약, 화면·사용 흐름을 서로 다른 Luna 에이전트가 평가한다.
- 각 평가자는 작업별 100점 만점 세부 기준, 점수, 파일 또는 실행 근거, 감점 사유를 남긴다.
- 모든 작업이 세 평가에서 각각 90점 이상이어야 한다. 평균으로 낮은 점수를 가리지 않는다.
- 문서만 보고 실행과 화면의 일관성을 통과시키지 않는다. 실제 로더·렌더링·로컬 경로·회귀 결과를 확인한다.
- 깨진 실행 경로, 숨은 정책, 끊어진 필수 화면, 검증되지 않은 핵심 계약이 있으면 해당 평가의 최고 점수는 89점이다.
- 업무상 필요한 차이(속성 개수, 허용값, 이미지 입력, 사용 가능한 데이터)는 설정과 명시적 기능 차이로 표현한다. 같은 기능의 뼈대는 공통 구현을 사용한다.
- 수정 뒤에는 재평가하며 최초 평가 기록을 보존한다. 점수 목표에 맞추려고 평가 기준을 낮추지 않는다.

## 보호할 자료

사람의 정답·판례·검수 원장과 이미 완료된 100개 실험 기록은 수정하지 않는다. 운영 DB 및 외부 시스템에 쓰지 않는다. 구조 확인에 필요한 로컬 테스트와 화면 확인을 수행한다.
